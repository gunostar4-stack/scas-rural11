# Smart Crop Advisory System (SCAS)

## Leaf disease scanner

The scanner accepts a leaf image, displays a local preview, and attempts Gemini Vision analysis when an internet connection and API key are available. Create `.env.local` from `.env.example` and set `VITE_GEMINI_API_KEY` to enable the demo integration. The API key is exposed to the browser in this Vite demo, so use a restricted development key only; production deployments should call Gemini through a protected server endpoint.

When offline, when no key is configured, or when Gemini fails, SCAS automatically shows a typed recommendation from its locally cached disease guidance.
